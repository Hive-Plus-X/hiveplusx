# HPX-CAM (巣箱・巣門カメラ) のファーム

Seeed Studio XIAO ESP32S3 Sense で、決まった間隔で写真を撮り、Wi-Fi で HPX-Server (`server/cam_upload.php`) へ送るファームです。写真は HPX-note の「カメラ」のページで見られます。

| フォルダ | 内容 |
|---|---|
| `HPX_CAM_v1_00/` | **最新** (初めての版)。クラウドでコンパイルだけ確かめた。実機ではまだ確かめていない |

部品表と配線図は `hardware/wiring/` にあります (`HPX-CAM_KP1228D_pcb.png`)。

## 書き込み

1. Arduino IDE のボードマネージャーで「esp32 by Espressif Systems」(3.x) を入れる (HPX-Core と同じ)。追加のライブラリは要りません。
2. ボードは **XIAO_ESP32S3** を選ぶ。
3. **ツール → PSRAM → 「OPI PSRAM」** にする (これを忘れるとカメラが動きません)。
4. `HPX_CAM_v1_00.ino` を開いて書き込む。**電池を外して** USB だけで書き込んでください。
5. シリアルモニター (115200) を開くと、カメラのID と設定用 Wi-Fi の名前が出ます。

## はじめの設定

1. 電池を入れる (または RESET ボタンを押す) と、Wi-Fi「`HPX-CAM-xxxx`」が出ます (xxxx は機器ごとに違う)。
2. スマートフォンでこの Wi-Fi につなぎ (パスワード `12345678`、HPX-Core と同じ)、ブラウザで `http://192.168.4.1/` を開きます。
3. 次を入れて「保存」します。
   - Wi-Fi の名前 (SSID) とパスワード … 蜂場のルーター (2.4GHz)
   - サーバーのアドレス … 例 `https://hiveplusx.com/hpx/`。HPX-Core の送信先 (`…/receive.php`) をそのまま入れても、同じフォルダの `cam_upload.php` へ送ります
   - 機器用トークン … HPX-note の「マイアカウント」に出る、HPX-Core と同じトークン
   - カメラの名前 (任意) … 初めて届いたときだけ HPX-note に使われます。あとは HPX-note のカメラの設定で変えます
   - 写真の大きさ … ふつうは SVGA 800×600 (LTE ルーターの通信量・電池のため)
   - 上下・左右を逆にする … カメラを逆さに付けたとき
   - 送り方 … 「撮るたびに送る」(おすすめ) か「1時間に1回まとめて送る」(電池が長もち)
4. 「試し撮り」で向きとピントを確かめ、「接続テスト」で試しに1枚送ります。HPX-note のメニュー「カメラ」に写真が出れば成功です。
5. 「設定を終えて撮影を始める」を押す (または 3分そのままにする) と撮影を始めます。

設定を変えたいときは、電池を入れ直すか RESET ボタンを押すと、また設定用 Wi-Fi が出ます。設定する前のまま 10分たつと、電池を守るため 6時間眠ります。

## 動き方

- 撮影の間隔 (5・10・15・30・60分) と撮影する時間帯 (初めは 5時〜19時) は **HPX-note のカメラのページ** で決めます。写真を送ったときのサーバーの返事でカメラに届き、次の撮影から使います。
- 撮影は時計の区切り (10分なら :00 :10 :20 …) で行い、時間帯の外は次の時間帯の始めまで眠ります (ディープスリープ)。時計はサーバーの返事と NTP で合わせます (日本時間)。
- 撮った写真はまず microSD の `/hpxcam/q/` にためて、送れたら `/hpxcam/YYYYMMDD/HHMMSS.jpg` へ移して残します。送れなかった写真は次に起きたときに新しい順に送り直します (1回に最大12枚・60秒まで)。
- microSD が 9割まで埋まったら、送った写真を古い日から消します (送っていない写真は消しません)。microSD は 32GB まで (FAT32)。microSD が無くても動きますが、送れなかった写真は残りません。
- 電池が 3.6V より下がったら撮らずに1時間眠ります (この値は XIAO の 5V 入口の下限からの目安で、実測していません)。
- 送るもの: 写真 (JPEG)、撮影時刻、電池の電圧 (`bv`)、Wi-Fi の電波の強さ (`rssi`)、名前。HPX-note のカメラのページに電池の電圧が出ます。

## 確かめていないこと

- 実機での動作全部 (写真の明るさ、送信、眠る・起きる、microSD)。
- 眠っている間の電流。Sense 基板のカメラは電源を切るピンがつながっていないので、眠っている間もカメラに電気が流れる可能性があります。電池のもち (見込み 昼12時間で約1〜3か月) は実測で確かめる必要があります。
- 体内時計のずれ。長く眠ると数十秒ずれることがあるので、最大90秒早く起きたときは区切りまで待ち、3時間より長くは続けて眠らないようにしています。
- OV5640 (自動ピント) のピント合わせ。v1.00 では自動ピントの命令を送っていません (OV5640 はピントが合わないかもしれません)。OV3660・OV2640 は固定ピントです。
- LTE-M の蜂場で HPX-Core に中継してもらう送り方 (HPX-Core 側の中継もまだありません)。
