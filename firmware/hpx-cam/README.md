# HPX-CAM (巣箱・巣門カメラ) のファーム

Seeed Studio XIAO ESP32S3 Sense で、決まった間隔で写真を撮り、Wi-Fi で HPX-Server (`server/cam_upload.php`) へ送るファームです。写真は HPX-note の「カメラ」のページで見られます。

## 書き込み

1. Arduino IDE のボードマネージャーで「esp32 by Espressif Systems」(3.x) を入れる (HPX-Core と同じ)。追加のライブラリは要りません。
2. ボードは **XIAO_ESP32S3** を選ぶ。
3. **ツール → PSRAM → 「OPI PSRAM」** にする (これを忘れるとカメラが動きません)。
4. `HPX_CAM_v1_10.ino` を開いて書き込む。**電池を外して** USB だけで書き込んでください。
5. シリアルモニター (115200) を開くと、カメラのID と設定用 Wi-Fi の名前が出ます。

## はじめの設定 (HPX-Core と同じ手順)

1. 電源を入れる (電池を入れる) と、HPX-Core と同じく Wi-Fi「`HPX-Setup-xxxx`」が出ます (xxxx は機器ごとに違う)。
2. スマートフォンでこの Wi-Fi につなぎ (初期パスワード `12345678`)、ブラウザで `http://192.168.4.1/` を開きます。
3. **ネットワークを設定する**: SSID (ルーターの Wi-Fi の名前、2.4GHz)、Wi-Fiパスワード、管理画面のパスワード (6〜32文字。ユーザー名は admin) を入れて保存します。接続方法は Wi-Fi、動作モードはディープスリープに決まっています (画面には表示だけ)。
4. **管理画面のURL を控える**: HPX-Core と同じく、その場で試しにルーターへつなぎ、管理画面のURL (`http://(IPアドレス)/` と `http://<機器ID>.local/`。機器ID は初め `hpx-cam-` ＋ MAC アドレスの最後の6けた) を表示します。控えたら「URLを控えました」にチェックして OK を押すと、再起動して切り替わります。つながらなかったときは、その場で入れ直せます。
5. **送り先を入れる**: スマートフォンをルーターの Wi-Fi に戻し、控えた URL で管理画面を開きます (ユーザー名 admin)。「動作設定」に、送信先のURL (HPX-note の入口のフォルダ、例 `https://hiveplusx.com/hpx/`。`cam_upload.php` は自動で補います。HPX-Core と同じ `…/receive.php` を入れても同じフォルダの `cam_upload.php` へ送ります) とトークン (HPX-note のマイアカウントに出る機器用トークン) を入れます。カメラの名前 (任意)、写真の大きさ (ふつうは SVGA 800×600)、上下を逆にする (写真が上下さかさまに写るとき)、左右を逆にする (v1.07 から、左右が反対に写るとき)、送り方 (「撮るたびに送る」がおすすめ、「1時間に1回まとめて送る」は電池が長もち) もここで決めます。
6. **届いたことを確かめる**: 動作設定を保存すると、写真を1枚撮ってサーバーへ送り、結果を出します。HPX-note のメニュー「カメラ」に写真が出れば成功です。カメラの向きとピントは管理画面の「試し撮り」で確かめます。
7. 「管理画面を終えて撮影を始める」を押す (または約10分そのままにする) と撮影を始めます。

| | |
|---|---|
| 管理画面を開くには | スマートフォンやパソコンを HPX-CAM と同じルーターにつなぎ、控えた URL を開きます。HPX-CAM は撮影中は眠っているので、**電源を入れなおしてから約10分の間**だけ開けます (HPX-Core の電池のときと同じ) |
| ルーターにつながらないとき | 電源を入れたときにルーターにつながらなければ、設定用 Wi-Fi「`HPX-Setup-xxxx`」が出ます。つないで `http://192.168.4.1/` を開き、ネットワーク設定を直します |
| 機器ID を変える | HPX-Core と同じく、管理画面の「機器ID変更」で変えられます (半角英小文字・数字・ハイフン)。変えると管理画面の名前の URL が `http://<新しい機器ID>.local/` になります。HPX-note に出るカメラの名前とは別で、そちらは HPX-note のカメラのページで変えます |
| 最初からやり直す | 電源を入れなおし、3秒以内に BOOT ボタンを5秒長押しすると、設定が消えて初めの状態に戻ります |
| 設定が済む前 | 30分たつと、電池を守るため6時間眠ります (HPX-Core と同じ) |

## ファームウェアの自動更新 (HPX-Core と同じしくみ、v1.02 から)

- 管理画面「動作設定」の「ファームウェアを自動更新する」にチェックします (v1.09 から。初めはオン)。確認先は送信先のURLから自動で決まり、写真の送り先 `cam_upload.php` と同じフォルダの `firmware/manifest_cam.txt` (2行のテキスト) を見ます。送信先が `https://` のときだけ使えます。
- v1.08 までは「ファームウェア自動更新サーバーのURL」にマニフェストの URL を入れていました。v1.09 に更新すると、URL を入れていた機器は「自動更新する」がオン、空欄だった機器はオフになります。
- 撮影で起きたとき、**1日1回** (HPX-Core の電池のときと同じ) マニフェストを見て、ビルド番号が今のファームより大きければ、`.bin` を受け取って書き込み、再起動します。マニフェストを読めなかったときは1時間後にもう一度見ます。電池が 4.0V より低いときは更新しません。
- 新しいファームで初めて起きたとき Wi-Fi につながれば「動いた」とし、つながらなければ前のファームへ戻します (ロールバック)。
- **すぐ確かめたいとき (v1.08 から)**: 管理画面 (電源を入れなおしてから約10分開けます) の「今すぐ更新を確認」を押すと、その場でマニフェストを読み、新しい版があれば書き込んで再起動します (1〜2分)。最新なら「最新です」と出ます。管理画面には「自動更新の確認」として、前の確認の時刻と結果も出ます。
- 手で更新するときは、管理画面の「ファームウェア更新」で `*.ino.bin` を選びます。

### 新しいファームを配るとき (サーバー管理者)

1. `FW_BUILD` を +1、`FW_VERSION` も変える (例 v1.03 なら build 103)。
2. Arduino IDE の「スケッチ」→「コンパイルしたバイナリを出力」で `*.ino.bin` を作る。
3. その `.bin` と、次の2行の `manifest_cam.txt` を、サーバーの HPX-note のフォルダの `firmware/` に置く (HPX-Core の `manifest.txt` とは別のファイル)。

```
102
https://example.com/hpx/firmware/HPX_CAM_v1_02.ino.bin
```

v1.09 からの HPX-CAM は、送信先と同じ場所の `firmware/manifest_cam.txt` を自分で見に行きます (別の場所には置けません)。

## 動き方

- 撮影の間隔 (5・10・15・30・60分) と撮影する時間帯 (初めは 5時〜19時) は **HPX-note のカメラのページ** で決めます。写真の大きさも HPX-note で選べます (v1.04 から。選んだときは管理画面の設定より優先)。写真を送ったときのサーバーの返事でカメラに届き、次の撮影から使います。
- 撮影は時計の区切り (10分なら :00 :10 :20 …) で行い、時間帯の外は次の時間帯の始めまで眠ります (ディープスリープ)。時計はサーバーの返事と NTP で合わせます (日本時間)。
- 撮った写真はまず microSD の `/hpxcam/q/` にためて、送れたら `/hpxcam/YYYYMMDD/HHMMSS.jpg` へ移して残します。送れなかった写真は次に起きたときに新しい順に送り直します (1回に最大12枚・60秒まで)。
- microSD が 9割まで埋まったら、送った写真を古い日から消します (送っていない写真は消しません)。microSD は 32GB まで (FAT32)。microSD が無くても動きますが、送れなかった写真は残りません。
- 電池が 3.6V より下がったら撮らずに1時間眠ります (この値は XIAO の 5V 入口の下限からの目安で、実測していません)。
- 送るもの: 写真 (JPEG)、撮影時刻、電池の電圧 (`bv`)、Wi-Fi の電波の強さ (`rssi`)、名前、ケースの温度 (`tc`、v1.05 から)、ファームのビルド番号 (`fw`、v1.06 から。HPX-note のカメラのページに「v1.06」と出る)。
- ケースの温度: 起きた直後 (Wi-Fi・カメラを動かす前) に ESP32-S3 の中の温度センサでチップの温度を測ります。正確な気温ではなく目安です。HPX-note のカメラのページで決めた温度 (初め 60℃) 以上になると「機器の警報」のメール・LINE でお知らせし、5℃ 下がると「戻りました」を送ります。HPX-note のカメラのページに電池の電圧が出ます。

## 確かめていないこと

- 実機での動作全部 (写真の明るさ、送信、眠る・起きる、microSD)。
- 眠っている間の電流。Sense 基板のカメラは電源を切るピンがつながっていないので、眠っている間もカメラに電気が流れる可能性があります。電池のもち (見込み 昼12時間で約1〜3か月) は実測で確かめる必要があります。
- 体内時計のずれ。長く眠ると数十秒ずれることがあるので、最大90秒早く起きたときは区切りまで待ち、3時間より長くは続けて眠らないようにしています。
- OV5640 (自動ピント) のピント合わせ。v1.00 では自動ピントの命令を送っていません (OV5640 はピントが合わないかもしれません)。OV3660・OV2640 は固定ピントです。
- LTE-M の蜂場で HPX-Core に中継してもらう送り方 (HPX-Core 側の中継もまだありません)。
