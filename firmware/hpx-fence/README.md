# HPX-F (電柵アラート) のファーム

StaFIX フェンスアラートの LED の点滅 (電柵の電圧低下) を光センサで数え、BLE の広告で HPX-Core へ知らせる、Seeed XIAO nRF52840 のファームです。
組み込み手順は [docs/server-setup.md](../../docs/server-setup.md) にあります。

2026-11-08 に機器名を **HPX-A から HPX-F** (Fence = 電柵) に変えました。ほかの機器 (HPX-TH = 温湿度、HPX-W = 重さ、HPX-B = バッテリー) と同じく「見ているもの」の頭文字にそろえるためです。

| フォルダ | 内容 |
|---|---|
| `HPX_F_v1_05/` | **最新**。v1.04 から電波を +8 dBm に強くし、広告を2秒間隔にした版 (広告の形式は同じ)。**HPX-Core v1.23 以降**と組み合わせる |
| `HPX_F_v1_04/` | 1つ前の版 (電波 0 dBm・広告1秒間隔)。v1.03 から名前と BLE 広告の種類の文字 ('A' → 'F')・広告の名前 ("HPX-alert" → "HPXF") だけを変えた版。**HPX-Core v1.23 以降**と組み合わせる |
| `HPX_Alert_v1_03/` | 名前が HPX-A のころの版 (広告 'A')。HPX-Core v1.22 以前が受け取る形。新しい HPX-Core では使えない |
| `HPX_Alert_v1_02/` | 古い版。電池電圧を測ったあと光センサが 0 を読み続ける不具合あり |
| `HPX_Alert_v1_00/` | 古い配線 (D0 のデジタル入力) 用の v1.01 |

**組み合わせの注意**: HPX-F (v1.04 以降) と HPX-Core (v1.23 以降) は、両方とも書き込み直してください。片方だけ新しくすると、HPX-Core が電柵アラートを受け取れません (登録画面の周辺検索にも出ません)。
