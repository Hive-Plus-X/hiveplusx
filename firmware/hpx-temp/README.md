# HPX-TH (温湿度センサ)

XIAO nRF52840 を使う巣箱の温湿度センサです。SHT40 で温度・湿度を、サーミスターでもう1点の温度を測り、BLE の広告で HPX-Core へ送ります。

| ファイル | 内容 |
|---|---|
| `HPX_TH_v1_02/` | HPX-TH v1.02 のファーム (最新)。v1.01 から電波を +8 dBm に強くし、広告を2秒間隔にした版。受け取るには HPX-Core v1.16 以降 (`firmware/hpx-core/HPX_Core_v1_16/`) が必要 |
| `HPX_TH_v1_01/` | 1つ前の版 (電波 0 dBm・広告1秒間隔)。受け取るには HPX-Core v1.16 以降 (`firmware/hpx-core/HPX_Core_v1_16/`) が必要 |
| `HPX_TH_v1_00/` | 古い版。2回目の測定からサーミスターが読めなくなる不具合があるので使わない |

## 部品と配線

部品表と配線図は `hardware/wiring/` にあります (`HPX-TH_pcb.png`)。

- SHT40 モジュール: VIN→3V3、GND→GND、SDA→D4、SCL→D5
- サーミスター 10kΩ: D3 ──[10kΩ 1%]── A2、A2 と GND の間にサーミスターと 0.1µF
- 電池: CR123A を 3V3 と GND へ直接 (USB で書き込むときは電池を外す)

## 書き込み

1. Arduino IDE のボードマネージャーで「Seeed nRF52 Boards」を入れ、ボードは「Seeed XIAO nRF52840」を選ぶ (HPX-W と同じ)。追加のライブラリは要りません。
2. `HPX_TH_v1_02.ino` を開いて書き込む。
3. シリアルモニター (115200) を開くと、次のように出ます。

```
HPX-TH.1.02
BLE address: XX:XX:XX:XX:XX:XX  (ハブの登録画面に出るアドレスと同じ)
#1 SHT40 24.31C 55.12%  サーミスター 24.10C  ノード内 25.00C  電池 3010mV
```

「SHT40 読めない」と出たら SHT40 の配線 (SDA・SCL の入れ違い) を、「サーミスター 読めない」と出たらサーミスターと 10kΩ の配線を確認してください。

## 動き方

- 電池を入れて (またはリセットして) から 5分間は 10秒ごと、そのあとは 10分ごとに測ります (`MEASURE_INTERVAL_MS` で変えられます)。
- 測った値を広告 (2秒間隔、電波の強さ +8 dBm) で出し続けるだけで、接続やペアリングはしません。
- HPX-Core の管理画面「温湿度計の登録」→「周辺のセンサを探す」で `[温湿度センサ HPX-TH]` と出た行に名前を付けて登録します。

## 校正

- SHT40 は工場で校正済みなので、そのまま使えます。
- サーミスターは部品の誤差で ±0.5℃ くらいずれることがあります。気になるときは、サーミスターの先を SHT40 のそばに30分ほど置き、シリアルモニターの2つの温度の差を `TH_OFFSET_C` に入れて書き込み直します (表示 − 正しい値)。

## 広告データ (メーカーデータ 16バイト)

| バイト | 内容 |
|---|---|
| 0..1 | 0xFF 0xFF (試験用の会社ID。HPX-W・HPX-F と同じ) |
| 2 | 'T' |
| 3 | 版 = 1 |
| 4..5 | 通し番号 (uint16, LE) |
| 6..7 | SHT40 の温度 ×100 (int16, LE)。0x7FFF = 測れなかった |
| 8..9 | 湿度 ×100 (uint16, LE)。0xFFFF = 測れなかった |
| 10..11 | サーミスターの温度 ×100 (int16, LE)。0x7FFF = 測れなかった |
| 12..13 | ノード内の温度 ×100 (int16, LE)。参考 |
| 14..15 | 電池電圧 mV (uint16, LE)。0 = 測れなかった |

広告の名前 (スキャン応答) は `HPXT` です。

## 確認できていないこと

- コンパイルと実機での動作はまだ確認していません。
- SHT40 モジュールの I2C アドレスは 0x44 を前提にしています (0x45 の品種もあります)。
- SHT40 モジュールに電源ランプ (LED) が付いていると、電池が早く減ります。
- CR123A でどれくらい持つかは、待機電流を測ってから見積もります。
