HPX System 1

サーバーの導入方法

HPX-Core から届いた記録を保存し、養蜂管理アプリ HPX-note を表示するサーバー HPX-Server を用意します。PHP が使えるレンタルサーバーに、ファイルを置くだけで動きます。データベースはいりません。

開発者は、さくらのレンタルサーバ (ライトプラン) で動かしています。ほかのレンタルサーバーでも動く見込みですが、まだ確かめていません。

サーバー
PHP が動き、https:// で開けるレンタルサーバー (開発では PHP 8.3 で確認)
メール
お知らせメールを送るための Gmail のアカウント (2段階認証とアプリパスワードを使います)
定期実行
15分ごとに見張りのページを動かすしくみ。サーバーの CRON か、無料の外部サービス (cron-job.org など)
  1. ファイルをダウンロードするGitHub の server フォルダ一式をダウンロードします。
  2. 設定ファイルを作るconfig.sample.php をコピーして config.php という名前にし、メモ帳などで開いて書き換えます。最初に決めるのは次の項目です。
    $HPX_VIEW_PASSWORD
    最初の管理者アカウントを作るときの合言葉 (8文字以上)
    $HPX_MAIL_FROM / $HPX_SMTP_USER
    メールを送る Gmail のアドレス
    $HPX_SMTP_PASS
    Gmail のアプリパスワード (16文字)
    $HPX_CRON_TOKEN
    外部サービスから定期実行するときの合言葉 (英数字20文字以上。CRON が使えるなら空欄)
    $HPX_SITE_URL
    サーバーの住所 (例 https://example.com/hpx)
  3. アップロードするレンタルサーバーの公開フォルダに hpx フォルダを作り、中身をすべて入れます。data フォルダの中の .htaccess (ブラウザから記録を開けないようにする設定) も必ず入れてください。
  4. 管理者アカウントを作るブラウザで https://(あなたのドメイン)/hpx/login.php を開きます。初期設定の画面が出るので、$HPX_VIEW_PASSWORD の合言葉を入れ、あなたのメールアドレス (ログインID になります) とパスワードを決めます。
  5. 定期実行を設定するhpx_cron.php を15分ごとに動かします。HPX-Core から届かなくなったときや、タスクの期限のお知らせに使います。
    CRON があるとき
    /usr/local/bin/php /home/(アカウント名)/www/hpx/hpx_cron.php (置いた場所に合わせる)
    CRON が無いとき
    外部サービスから https://(ドメイン)/hpx/hpx_cron.php?k=(合言葉) を呼ぶ。ブラウザで開いて ok と出れば成功
  6. 使う人を登録するHPX-note の「サーバー管理」で、登録のしかた (招待 / 申請して承認 / 自由登録) を選びます。家族や仲間と使うときは、チーム機能で記録を共有できます。
  7. HPX-Core 用の情報を控えるHPX-note の「マイアカウント」→「HPX-Core の接続」に、送信先のURL とトークン (合言葉) が出ます。次の「HPX-Core の設定」で使います。

config.php と data フォルダには、パスワードや記録が入っています。人に見せたり、GitHub などに上げたりしないでください。

HPX System 2

HPX-Core の設定

HPX-Core に、どのネットワークにつなぐかと、記録の送り先を教えます。設定はスマートフォンのブラウザだけでできます。

HPX-Core の作り方とファームウェアの書き込みは、HPX-Core の機器ページを見てください (Arduino IDE、ボードは ESP32 Dev Module、パーティションは Minimal SPIFFS)。

HPX-Core
ファームウェアを書き込んだもの
スマートフォン
設定用の Wi-Fi につないで、ブラウザで設定します
ルーターの情報
Wi-Fi でつなぐときは、ルーターの Wi-Fi の名前 (SSID) とパスワード。2.4GHz の Wi-Fi だけ使えます
サーバーの情報
前の章で控えた、送信先のURL とトークン
  1. 設定用の Wi-Fi につなぐHPX-Core に電源を入れると、HPX-Setup-xxxx という Wi-Fi が出ます (xxxx は機器ごとに違います)。スマートフォンでこの Wi-Fi につなぎ (初期パスワード 12345678)、ブラウザで http://192.168.4.1/ を開きます。
  2. ネットワークを設定する接続方法 (Wi-Fi か有線LAN)、Wi-Fi の名前とパスワード、管理画面のパスワード (6〜32文字。ユーザー名は admin)、動作モードを入れて保存します。コンセントやソーラーで電気が来るなら、動作モードは「常時稼働」を選びます。
  3. 管理画面のURL を控えるWi-Fi のときは、HPX-Core がその場で試しにつなぎ、管理画面のURL (http://(IPアドレス)/ と http://(機器ID).local/) を表示します。控えたら「URLを控えました」にチェックして OK を押すと、再起動して切り替わります。つながらなかったときは、その場で入れ直せます。
  4. 送り先を入れる管理画面の「動作設定」に、送信先のURL とトークンを入れます。記録の間隔 (15分・30分・60分。初めは30分) もここで選びます。「ファームウェア自動更新サーバーのURL」は空欄でも動きます。
  5. 届いたことを確かめる次の記録の時刻を過ぎたら、HPX-note のセンサページに HPX-Core が出ます。蜂場のページで「この蜂場の HPX-Core」にチェックを入れると、蜂場とつながります。
有線LAN のとき
再起動したあとも、管理画面用に HPX-Setup-xxxx の Wi-Fi が出たままになります。管理画面は、この Wi-Fi につないで http://192.168.4.1/ で開きます。
管理画面を開くには
スマートフォンやパソコンを、HPX-Core と同じルーターにつないでおきます。HPX-note のセンサページの「管理画面を開く」からも開けます。ディープスリープ (電池) のときは、RESET ボタンを押してから約10分だけ開けます。
最初からやり直す
RESET ボタンを押して離し、3秒以内に BOOT ボタンを5秒長押しすると、設定が消えて初めの状態に戻ります。
ソーラーの電圧を見る
「＋有線LAN＆ソーラーシステムチェック」版では、動作設定の「バッテリー・パネルの電圧を測る」にチェックし、テスターで測った値を入れて合わせます。

HPX System 3

センサの登録方法

センサは、HPX-Core の管理画面で登録します。センサは Bluetooth で発信しているだけなので、ペアリングはいりません。1台の HPX-Core に10台まで登録できます。

登録は、HPX-Core とセンサを手元に並べて、家でしておくのがおすすめです。

HPX-W
重量センサ (巣箱の重さ)
HPX-TH
温湿度センサ (巣箱の中の温度・湿度)
HPX-F
電柵アラート (電柵の電圧低下)
市販温湿度計
Inkbird IBS-TH2 / TH2 PLUS、SwitchBot 温湿度計 / 防水温湿度計、BroodMinder-TH2
市販重量センサ
BroodMinder-W5・W+ (巣箱の片側に置き、センサの値の2倍を巣箱の重さにします)、BroodMinder-W3・W4 (巣箱全体を乗せるので、巣箱の重量を正確に測れます)。最初に数 kg (例: 約 −3.5kg) のずれが出ることがあるので、巣箱を乗せる前にセンサのページの「風袋引き」で 0kg にそろえてください
HPX-B
バッテリー電圧 (準備中)
  1. センサに電池を入れる電池を入れたセンサを、HPX-Core から1〜2m のところに置きます。
  2. 周りのセンサを探すHPX-Core の管理画面で「センサの登録」→「周辺のセンサを探す」を押します。約8秒で、見つかったセンサが電波の強い順に並びます。[重量センサ] [温湿度センサ HPX-TH] [電柵アラート] のように種類も出ます。
  3. 名前を付けて登録する「1番箱 重さ」「1番箱 温度」のように、どの巣箱のものかわかる名前を付けて登録します。センサ本体にも同じ名前のラベルを貼っておくと、設置のときに迷いません。
  4. 重量センサを較正するHPX-W は、管理画面の「重量センサの較正」で、何も載せないときと、重さのわかる物を載せたときの2回測って、kg に直せるようにします。
  5. 巣箱・蜂場とつなぐHPX-note の巣箱のページで、その巣箱の HPX-W・HPX-TH を選びます。電柵アラート HPX-F は、蜂場のページで選びます。選べるのは、その蜂場の HPX-Core に登録したセンサだけです。

近くにほかの人のセンサがあると、一覧に出ることがあります。手元のセンサは、ふつう一覧のいちばん上 (電波がいちばん強い) に出ます。迷ったときは、センサの電池を抜いてもう一度探し、消えたものが手元のセンサです。

Apiary 1

電源の確保

HPX-Core とルーターは、一日中電気を使います。蜂場に合わせて電源を選びます。センサ (HPX-W・HPX-TH・HPX-F) は電池で動くので、電源はいりません。

コンセントの無い蜂場では、ソーラーパネルで 12V のバッテリーを充電して使います。下はその組み方です。

コンセントがある
家庭用の 100V がいちばん安定していて、おすすめです。HPX-Core は USB の AC アダプター (5V) で動かします
コンセントが無い
ソーラーパネル＋チャージコントローラー＋12V バッテリー。発電とバッテリーの大きさに余裕がないと、雨が続いたときに止まることがあります
短い期間だけ
「＋防水＆電池駆動」版の HPX-Core (単三リチウム電池3本)。Wi-Fi が届く場所で使います。30分ごとの記録で3〜4か月の見込み (まだ実測していません)

ソーラーパネルとバッテリーで組む

ソーラーパネル
12V バッテリー用のもの。開発者は 100W のパネルを使っています。電池の入った小さなソーラーパネル (10W 以下のもの) では、毎日の電気をまかないきれないことがあります
チャージコントローラー
パネルの電気でバッテリーを充電し、使い過ぎを防ぐ機器。USB の出口が付いたものなら、HPX-Core をそこから動かせます。開発者は PWM 式 30A (12V/24V 兼用) を使っています
USB 電源ポート
コントローラーに USB の出口が無いときや足りないときに、12V を USB の 5V に変えるもの。機器が多いときは、配線を分ける端子台 (分岐ターミナル) があると便利です
12V バッテリー
車用のバッテリーで 60〜90Ah くらいのもの。開発者は 95D26L を使っています。ディープサイクル用ならさらに長持ちします
ヒューズ
バッテリーのプラスのすぐ近くに入れます。線がショートしたときの火事を防ぎます。小さすぎると、晴れた日の充電の電流で切れてしまうので、パネルの大きさと線の太さに合わせて選びます
箱
コントローラーとバッテリーを雨から守る箱。バッテリー用の収納ボックスや防水のプラスチックボックスのほか、使っていない古い巣箱もバッテリーが入り、機器をねじで留められるので便利です
  1. 使う電気を見積もる目安は、HPX-Core が1日に約1Ah、LTE ルーター (平均2W のもの) が1日に約4Ah で、合わせて1日 約5Ah (12V) です。鉛のバッテリーは半分より減らさないほうが長持ちするので、曇りや雨が5日続いても半分残る大きさ (50Ah 以上) を選ぶと安心です。秋の長雨や冬は発電が少ないので、パネルも余裕のある大きさ (100W くらい) にします。数字は目安です。まだ実測していません
  2. パネルの置き場所を決める一日中影がかからない場所に、南向きに置きます。冬は太陽が低いので、30度くらい傾けるか、少し立て気味にすると冬でも充電できます。風で飛ばないよう、しっかり固定してください。蜂の出入りの邪魔にならないよう、巣門の前は避けます。
  3. つなぐ順番を守るコントローラーに、①バッテリー → ②ソーラーパネル → ③HPX-Core やルーター の順でつなぎます。パネルを先につなぐと、コントローラーがバッテリーの電圧を正しく見分けられないことがあります。バッテリーをつないだらコントローラーの表示が出ること、パネルをつないだらパネルの表示が出ることを確かめながら進めます。外すときは逆の順番です。パネルは光が当たると電気が出るので、作業中は布などでおおっておきます。お使いのコントローラーの説明書に順番が書いてあれば、そちらに従ってください
  4. 機器はコントローラーの出口につなぐHPX-Core やルーターは、コントローラーの「負荷」の出口 (電球のマーク) か USB の出口につなぎます。コントローラーは、バッテリーが減りすぎると出口を止めてバッテリーを守ります (止まる電圧は機種ごとに決まっていて、変えられるものもあります)。機器が動かないときは、出口がオンになっているかを確かめてください。少し減っても止めたくない機器だけ、バッテリーに直接つなぎます (そのぶんバッテリーは傷みやすくなります)。
  5. 雨と熱から守るコントローラーとバッテリーは、雨の入らない箱に入れます。線のつなぎ目は自己融着テープで巻いて、水が入らないようにします。車用のような液を入れたバッテリーは、充電中にガスが出ることがあるので、箱を完全に閉め切らず、空気の通り道を作ります。夏の直射日光で箱の中が熱くなりすぎないよう、日陰に置きます。
  6. 電圧を見守る「＋有線LAN＆ソーラーシステムチェック」版の HPX-Core なら、バッテリーとパネルの電圧を HPX-note で見られます。バッテリーが 12.0V を下回るとメールで知らせます。

バッテリーのプラスとマイナスを直接つなぐと、大きな電流が流れて危険です。工具や金属をバッテリーの上に置かないでください。作業の前に、ヒューズを外しておくと安全です。

Apiary 2

ルーターの準備

HPX-Core は、ルーターを通してインターネットのサーバーへ記録を送ります。家の Wi-Fi が届く蜂場ならそのまま使うのがいちばん安上がりです。離れた蜂場では、携帯電話の電波 (LTE) を使う「LTE ルーター」に SIM カードを入れて使います。

モバイル Wi-Fi (ポケット型の Wi-Fi) も使えますが、電池が入っていて夏の暑さに弱く、機種によっては動きが不安定になります。ずっと置いておくなら、電池の入っていない機器向けの LTE ルーター (M2M ルーター、IoT ルーターとも呼ばれます) がおすすめです。

暑さ・寒さ
動作温度が広いもの (例 −20〜60℃)。家庭用は 0〜40℃ くらいが多く、夏の箱の中では足りません
電池
電池の入っていないもの。熱で電池がふくらむ心配がありません
電源
12V のバッテリーから直接動かせるもの (DC 入力) だと、ソーラーと組み合わせやすい
つなぎ方
Wi-Fi (2.4GHz) か、有線LAN の口。有線LAN だけのルーターには「＋有線LAN」版の HPX-Core を使います
SIM
使いたい携帯会社の SIM に対応しているもの。SIM の大きさ (標準・nano など) も確かめます
自動復旧
通信が止まったときに自分でつなぎ直す機能があると、蜂場まで行かずに済みます
  1. 蜂場の電波を確かめる使う予定の携帯会社のスマートフォンを蜂場に持っていき、電波が入るかを見ます。弱いときは、ルーターに外付けのアンテナを付けて、高い所に出すと良くなることがあります。
  2. SIM カードを用意するデータ通信用の SIM を用意します。機器向けの「IoT 用 SIM」には、年に数千円ほどの安いプランもあります。HPX-Core が送る記録は文字だけで小さいので、データ量の少ないプランで足りる見込みです (使う量はまだ実測していません)。同じルーターに防犯カメラもつなぐときは、映像でデータを多く使うので、プランを選び直してください。
  3. 家で設定するLTE ルーターに SIM を入れ、説明書に沿って接続の設定 (APN) をします。HPX-Core もつないで、HPX-note に記録が届くことを家で確かめてから蜂場へ持っていきます。
  4. 蜂場に置く雨の入らない箱に入れます。金属の箱の中では電波が通りにくいので、プラスチックの箱を使うか、アンテナを箱の外に出します。
開発者が試している機種
サン電子 Rooster RX220 (中古)。DC 5〜27.4V で動き、−20〜60℃、ドコモ・au・ソフトバンクの SIM に対応、有線LAN の口が2つあります。Wi-Fi は無いので「＋有線LAN」版の HPX-Core とつなぎます。蜂場での長期の動作はこれから確かめます。

Apiary 3

HPX-Core の設置

HPX-Core は、蜂場に1台置きます。センサの Bluetooth の電波を受けられて、ルーターにもつながる場所を選びます。

Bluetooth が届くのは、見通しの良い所で約10m が目安です。間に巣箱や地面、金属があると短くなります。

基本モデル
Wi-Fi＋USB 給電。小屋の中など、雨の当たらない場所に
＋防水
屋外にそのまま置くとき
＋有線LAN
Wi-Fi の無い LTE ルーターに LAN ケーブルでつなぐとき
＋有線LAN＆ソーラーシステムチェック
ソーラーのバッテリーとパネルの電圧も見たいとき
＋防水＆電池駆動
電源の無い所で、短い期間使うとき
  1. 置き場所を決める巣箱や電柵アラートから、なるべく近くて見通しの良い場所を選びます。地面に直接置かず、少し高い所に置くと電波が届きやすくなります。
  2. 雨と熱から守る防水版でなければ、雨の入らない箱や小屋の中に置きます。直射日光の当たる箱の中は夏にとても熱くなるので、日陰を選びます。
  3. 電源とルーターにつなぐUSB ケーブルで電源につなぎます (ソーラーシステムチェック版はバッテリーから)。有線LAN 版は、LAN ケーブルでルーターとつなぎます。
  4. センサの電波を確かめるスマートフォンで HPX-Core の管理画面を開き、「BLEセンサの記録」で、登録したセンサが全部受信できているかを見ます。届かないセンサがあれば、HPX-Core の位置や高さを変えます。
  5. HPX-note に届くまで待つ次の記録の時刻 (初めは30分ごと) を過ぎたら、HPX-note のセンサページに新しい記録が出るかを確かめてから、蜂場を離れます。

Apiary 4

センサの設置

登録したセンサを、巣箱や電柵に取り付けます。センサは電池で動くので、配線はいりません。取り付けたら、HPX-note で値が届いているかを確かめます。

登録したときの名前と、取り付ける巣箱が合っているかを確かめながら作業してください。

HPX-W
巣箱の下

重量センサ

HPX-W

巣箱の片側の下にロードセルを置き、巣箱の半分の重さを量ります。HPX-note では、1台なら2倍、同じ巣箱に2台なら合計を巣箱の重さとして出します。

  • 平らで固い台の上に、傾かないように置きます
  • 巣箱の重さが、ロードセル以外 (台の縁や周りの物) にかからないようにします
  • 置いたあと、HPX-note の重さが空の巣箱の重さに近いかを見ます

温湿度センサ

HPX-TH

巣箱の中の温度と湿度を測ります。温度はケースから出したサーミスター (細い線の先の温度センサ) で測ります。

  • サーミスターの先を、育児圏 (幼虫やさなぎのいる巣枠) の中心あたりに入れます
  • 本体は、蜂にふさがれたり、ふたで線をつぶしたりしない位置に置きます
  • 内検のときに引っかけないよう、線をまとめておきます
HPX-TH の機器ページ
電柵アラート

HPX-F

電柵のフェンスアラートの LED の点滅を、光センサで電線をつながずに読み取ります。

  • 光センサを、フェンスアラートの赤いカバーに向けて貼ります
  • 日光が入らないよう、赤いカバーごと黒いキャップやテープでおおいます
  • フェンスアラートの回路と HPX-F を、電線でつながないでください (電柵の高い電圧がかかります)
  • LED が点滅するたびに、HPX-F の赤いランプが一瞬光れば、読み取れています
機器の一覧
  1. 取り付ける上のそれぞれの注意に沿って取り付けます。
  2. HPX-Core の受信を確かめる取り付けた場所からも電波が届いているかを、HPX-Core の管理画面「BLEセンサの記録」で確かめます。巣箱の中や地面に近い所は、電波が弱くなりがちです。
  3. HPX-note で値を見る次の記録の時刻を過ぎたら、巣箱のページで重さ・温度・湿度が出ているかを見ます。電池の残りもセンサページで見られます。
