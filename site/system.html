System

しくみ

巣箱のセンサで測った値が、ハブ、ルーター、サーバーを通って、アプリに届くまでの流れです。

全体の流れ

センサは Bluetooth で値を発信し、蜂場のハブ HPX-Core が受け取ります。HPX-Core はルーターを通してインターネットにつながり、記録をサーバーへ送ります。サーバーに貯まった記録は、HPX-note でどこからでも見られます。

センサ　HPXシリーズ重量・温湿度、その他各種センサを開発中です
ハブ　HPX-Coreセンサを管理し、データをサーバーに送る中心的な機器です
ルーター市販のLTEルーターなどをご利用ください
サーバーレンタルサーバーなどに自分専用のシステムを構築します
養蜂管理アプリ　HPX-noteデータと記録をグラフなどで確認できます

Sensors

センサ　HPXシリーズ

巣箱や電柵のそばに置く、電池で動く小さな機器です。測った値を Bluetooth で1秒ごとに発信し続けます。ハブとの接続やペアリングはいりません。

どのセンサも、電池の電圧をいっしょに送ります。電池が少なくなると、アプリに交換の目安が出ます。

機器の作り方を見る
HPX-W
巣箱の重さ。30分ごとに測ります
HPX-TH
巣箱の温度と湿度。10分ごとに測ります
HPX-A
電柵のフェンスアラートの点滅を光で読み取り、電圧の低下を知らせます
電源
単三リチウム電池2本、または CR123A 1本

Hub

ハブ　HPX-Core

蜂場に1台置く、中心になる機器です。まわりのセンサの電波を受け取って本体に貯め、Wi-Fi でサーバーへ送ります。

通信が切れている間の記録は本体に残り、つながったときにまとめて送ります。プログラムの更新も、サーバーから自動で受け取れます。

受け取れる数
センサ 8台まで
送り先
自分のサーバー (HTTPS で暗号化して送ります)
電源
USB (5V)。電源を入れたまま使います
設定
スマートフォンから HPX-Core の設定画面を開いて行います

Router

ルーター

HPX-Core をインターネットにつなぐための Wi-Fi です。家の近くなら家の Wi-Fi、離れた蜂場なら市販の LTE ルーターなどを使います。

ルーターは HPX の機器ではなく、市販品をそのまま使います。

家の近く
自宅の Wi-Fi ルーター
離れた蜂場
SIM を入れて使う LTE ルーター、モバイル Wi-Fi など

Server

サーバー

HPX-Core から届いた記録を受け取り、保存します。重さの換算や、電柵の電圧低下などの知らせもサーバーが行います。

記録は文字だけのファイルで保存するので、データベースを用意しなくても動きます。PHP が使えるレンタルサーバーに置けます。

保存
センサの記録、メモ、作業の記録
知らせ
電柵の電圧低下や機器の異常を、メールで送ります
置き場所
自分のレンタルサーバーなど

App

養蜂管理アプリ　HPX-note

サーバーの記録を、スマートフォンやパソコンのブラウザで見るウェブアプリです。重さや温湿度のグラフに加えて、内検のメモや作業の記録も残せます。

デモを開く詳しく見る
見られるもの
蜂場・巣箱ごとの重さと温湿度のグラフ、センサの状態
残せるもの
内検のメモと写真、作業の予定と記録
チーム
複数のメンバーで同じ蜂場を管理できます
