Data flow

データの流れ

センサで測った値が、HPX-note に表示されるまでの順番です。

  1. 測るセンサが、巣箱の重さ・温度・湿度や、電柵のフェンスアラートの点滅、ソーラーで充電するバッテリーの電圧を測ります。HPX-W 30分ごと / HPX-TH 10分ごと / HPX-F 0.02秒ごと (光を読む)
  2. 発信するセンサは、最新の値と電池の電圧を Bluetooth で発信し続けます。決まった相手につなぐのではなく、周りに知らせるだけなので電池が長持ちします。1秒ごと
  3. 集めるHPX-Core は、記録の時刻になるとセンサからの情報をとらえ、各センサの最新の値を本体に記録します。15分・30分・1時間ごと (設定で選ぶ。初期は30分)
  4. 送る記録したらすぐに、Wi-Fi でルーターからインターネットを通じてサーバーまで暗号化して送ります。送れなかった記録は貯めておき、次に送ります。記録のたびに
  5. 保存するサーバーは届いた記録を保存し、お知らせメールを出したり、データを補正したりします。届いたとき
  6. 見るHPX-note を開くと、サーバーの記録がグラフや表になって表示されます。いつでも

Sensors

センサ　HPXシリーズ

巣箱や電柵、バッテリーのそばに置く小さな機器です。測った値を Bluetooth で1秒ごとに発信し続けます。ハブとの接続やペアリングはいりません。

電池で動くセンサは、電池の電圧をいっしょに発信します。電池が少なくなると、アプリに交換の目安が出ます。

機器の作り方を見る
HPX-W (重さ)
巣箱の重さを30分ごとに測ります
HPX-TH (温湿度)
巣箱の温度と湿度を10分ごとに測ります
HPX-F (電柵)
電柵のフェンスアラートの点滅を光で読み取り、電圧の低下を知らせます
HPX-B (蓄電池)
ソーラーパネルで充電する 12V バッテリーとパネルの電圧を測ります。電源は見守るバッテリーから取ります (ファームウェアは準備中)
市販温湿度計
市販の Bluetooth センサも使えます。現在は、SwitchBot の温湿度センサと、Inkbird の温湿度センサに対応済みです
拡張性
Bluetooth で発信するセンサであれば HPX-Core で受信できるので、様々な拡張機器の開発・利用が可能です
電源
単三リチウム電池2本、または CR123A 1本 (HPX-B は見守る 12V バッテリーから)

Hub

ハブ　HPX-Core

蜂場に1台置く、中心になる機器です。まわりのセンサの Bluetooth を拾って記録し、Wi-Fi でサーバーへ送ります。

サーバーへの通信が途切れた場合は、記録を本体に3日分まで (センサ10台・15分ごとの記録では約2日分) 保存し、つながったときにまとめて送ります。HPX-Core のファームウェアプログラムのアップデートも、サーバーから自動で行えます。

センサの登録
周りのセンサを Bluetooth で探して一覧にし、使うものを選んで登録します (10台まで)
重量センサの初期校正
おもりを乗せない0kgと、重量のわかるものを乗せた時の値の2点校正を行います。
ルーターの設定
初めは HPX-Core が自分の Wi-Fiアドレス を出すので、スマートフォンでつないで、使うルーターの SSID とパスワードを設定します
記録の間隔
15分・30分・1時間から選べます (初期は30分。毎時00分・30分のような時計の区切り)
電源
商用電源がある場所では USB (5V) で常に動かします。ソーラーパネルとバッテリーで使用するときは、ディープスリープを活用した省電力モードを選べます

Router

ルーター

HPX-Core をインターネットにつなぐための機器です。家の近くなら家の Wi-Fi ルーター、離れた蜂場なら市販の LTE ルーターなどを使います。

ルーターは市販品をご準備ください。

家の近く
自宅の Wi-Fi ルーター
離れた蜂場
SIM を入れて使う LTE ルーター、モバイル Wi-Fi など

Server

サーバー　HPX-Server

HPX-Server は、HPX-Core から届いた記録を受け取り、保存します。重さの換算や温湿度の補正、電柵の電圧低下などの知らせもサーバーが行います。

記録は文字だけのファイルで保存するので、データベースを用意しなくても動きます。PHP が使えるレンタルサーバーに置けます。

保存
センサの記録、メモ、作業の記録
補正
温湿度計ごとに温度・湿度の補正値を決められます
知らせ
電柵の電圧低下や巣箱・機器の異常を、メールで送ります (下のお知らせメール一覧)

Alerts

お知らせメール一覧

サーバーは、次のようなときにメールで知らせます。件名の頭には【HPX】が付きます。

分類件名送るとき
電柵電柵の電圧が下がっていますフェンスアラートの点滅を HPX-F が続けて見つけたとき
電柵電柵の電圧が一時的に下がりました記録と記録の間に電圧低下があって、もう戻っているとき
電柵電柵の電圧が戻りました点滅が止まり、元に戻ったとき
電柵光センサが点灯したままです光センサがずっと明るいとき (日光が入っているなど、遮光を確かめる)
センサHPX-W / HPX-TH / HPX-F の電池を交換してください電池の電圧が下がったとき (HPX-W 2.8V・HPX-TH 2.7V・HPX-F 2.6V 未満)。センサページに交換が出るときと同じです
センサHPX-W / HPX-TH / HPX-F / 温湿度計 から受信できていませんセンサの記録が来ないとき (HPX-F は1時間、ほかは24時間)
巣箱温度が上限を超えました / 下限を下回りました巣箱ごとに決めた温度の上限・下限を外れたとき
巣箱温度が戻りました上限・下限の内側に戻ったとき
巣箱重量が基準日から増えました / 減りました採蜜した日などの基準日から、決めた重さ以上に増えた・減ったとき
バッテリーバッテリーの電圧が下がっていますソーラー用の 12V バッテリーの電圧が、知らせる電圧 (初期は 12.0V) より下がったとき (HPX-Core ＋有線LAN＆ソーラーシステムチェック。HPX-B は準備中)
バッテリーバッテリーの電圧が戻りましたバッテリーの電圧が戻ったとき (初期は 12.6V 以上)
ハブハブから届いていませんHPX-Core からの記録が1時間届かないとき (電源・Wi-Fi・ルーターを確かめる)
ハブハブからの受信が戻りましたHPX-Core からまた届くようになったとき
タスクタスクのお知らせ通知をオンにしたタスクの期限の前日・当日と、期限を過ぎて終わっていないとき (1日1回、人ごとに1通にまとめる)

巣箱の温度と重量の知らせは、巣箱のページで値を決めたものだけ送ります。電柵の知らせは、HPX-Core が記録する間隔 (15分〜1時間) ごとに届きます。

App

養蜂管理アプリ　HPX-note

サーバーの記録を、スマートフォンやパソコンのブラウザで見るウェブアプリです。重さや温湿度のグラフに加えて、内検のメモや作業の記録も残せます。

デモを開く詳しく見る
見られるもの
蜂場・巣箱ごとの重さと温湿度のグラフ、センサの状態
残せるもの
内検のメモと写真、作業の予定と記録
書き出し
センサの記録と、蜂場・巣箱・メモ・タスク・作業の記録をすべて CSV (Excel で開ける形) にして、まとめてダウンロードできます。写真も入れられます
チーム
複数のメンバーで同じ蜂場を管理できます
