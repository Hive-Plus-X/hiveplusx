Introduction

はじめに

自作する人には独自運用の土台として、学生や研究者には仕組みを学び改良する材料として使ってもらい、養蜂家と研究開発者がフィードバックし合うことで、技術開発と普及が促進していくことを目指します。

このページは、公開している物をどの条件で使えるか、名前とロゴの扱い、安全上の注意、参加のしかたをまとめたものです。正式なライセンス文は GitHub のリポジトリ の LICENSES フォルダにあり、食い違いがあればそちらが優先します。

Name & Logo

名前とロゴの扱い

「Hive Plus X」「hive+x」の名前とロゴは、上のライセンスの対象外です。コードや図面は自由に使えますが、名前を使うと「公式のもの」と受け取られるため、利用者が迷わないように次のルールをお願いしています。

自由にどうぞ避けてほしいこと
「Hive Plus X をもとに作りました」「Hive Plus X 互換」と書く改造したものを「Hive Plus X」の名前で配る・売る
記事・発表・授業で Hive Plus X を紹介する、ロゴを載せる自分の製品やサービスの名前・ロゴとして使う
作った機器をそのまま使う (改造していなければ名前もそのままでよい)ロゴの色・形を変える、公式の認定や推薦を受けたように見せる

ロゴの配色と余白のルールは ロゴの使い方 にあります。迷ったときは お問い合わせフォーム へどうぞ。

Contribute

貢献のしかた

不具合の報告、使ってみた感想、改良の提案は、どれも歓迎です。プログラムを書かない人の「ここが分かりにくい」も大事な貢献です。

  1. 質問・アイデア・使ってみた報告: フォーラム (GitHub Discussions) に書く。GitHub を使わない人は お問い合わせフォーム へ。機器を作った・使ったときは、写真付きで 作った・使ったレポート に投稿できます
  2. 不具合の報告: GitHub の Issues に書く。何をしたら、どうなったかを書く
  3. 直したものを送る: GitHub でプルリクエストを送る。何を、なぜ直したかを一言添える
  4. 確認と取り込み: 管理者が内容を見て、問題がなければ取り込む。機器に関わる変更は、できる範囲で実機で試してから取り込む

権利の扱い (DCO): プルリクエストの変更には、「Signed-off-by: 名前 <メールアドレス>」の一行を付けてください。これは「自分が書いたもの (または公開してよいもの) で、このプロジェクトと同じライセンスで公開されることに同意します」という宣言です (Developer Certificate of Origin)。著作権は書いた人に残り、譲渡してもらうことはありません。

くわしい手順は GitHub の CONTRIBUTING.md にあります。

Code of Conduct

行動規範

Hive Plus X には、趣味の養蜂家、プロの養蜂家、学生や研究者など、経験も立場も違う人が集まります。気持ちよく参加できる場にするため、次のことを約束してください。

  • 相手の経験や立場に関係なく、敬意を持って接する
  • 初めての人の質問を歓迎し、分かりやすく答える
  • 意見の違いは、人ではなく内容について話す
  • 個人攻撃、差別的な発言、嫌がらせ、他人の個人情報を勝手に出すことはしない
  • 他人の蜂場の場所やデータを、本人の同意なく公開しない

守られていないと感じたときは お問い合わせフォーム へ連絡してください。管理者が内容を確かめ、注意、投稿の削除、参加の停止などの対応をとります。連絡した人の名前は、本人の同意なく明かしません。

この規範は Contributor Covenant を参考に、Hive Plus X 向けに短くまとめたものです (GitHub の CODE_OF_CONDUCT.md)。

Versions & Data

版の管理とデータの扱い

版番号: 機器のプログラムは「v1.14」のように版番号を付けます。小さな修正は小数点以下 (v1.14 → v1.15)、それまでの設定や機器と互換性がなくなる大きな変更は先頭の数字 (v1 → v2) を上げます。サーバーとサイトも、まとめて公開するときに版番号を付けます。

変更履歴: 何がいつ変わったかは GitHub の履歴に残し、主な変更は版ごとの「変更点」としてまとめます。古い版も GitHub から取り出せます。

公開するものと、しないもの

公開する公開しない
機器のプログラム、回路図、部品表利用者のアカウント情報
サーバーのプログラム (設定ファイルを除く)蜂場の場所、巣箱の記録、センサの計測データ
説明書、作り方、ロゴパスワード、トークンなどの鍵

利用者のデータ: 利用者向けサーバーに集まったデータは非公開で、運営者 (養蜂産業振興会) が管理します。Hive Plus X は、個人や蜂場が特定できない形にしたうえで、養蜂の研究や AI の学習にデータを使うことがあります。データの扱いの細かい決まりは、利用者向けサーバーの利用規約で定めます。この方針は「コードをどう公開するか」を決めるもので、データの扱いは利用規約が優先します。

自分で用意したサーバーに Hive Plus X のプログラムを入れて使う場合、データはそのサーバーの持ち主のもので、Hive Plus X には送られません。
