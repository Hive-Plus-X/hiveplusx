# hive+x ロゴ 最終版 (2026-10-26)

ブランド名: Hive Plus X / ロゴ表記: hive+x。書体は Inter ExtraBold で、文字はアウトライン化済みです (フォントのインストールは不要)。i の点は六角形 (蜜のしずく・巣房) に置き換えています。

## 配色
| 名前 | HEX | 使いどころ |
|---|---|---|
| Charcoal | `#1F2328` | メインの文字色 |
| Honey | `#F2A900` | i の六角形と「+」 (全バージョン共通) |
| White | `#FFFFFF` | 明るい背景 / 暗い背景での文字色 |
| Forest | `#2F5D45` | 2番目のブランド色 (暗い背景用) |

## 使い方のルール
- ロゴの周りには、「h」の高さの半分以上の余白を空けてください。
- 色を変えたり、縦横比を変えたり、影を付けたりしないでください。
- 最小サイズは、画面なら幅 80px、基板シルクなら幅 8mm を目安にしてください (それより小さいと六角形が潰れやすくなります)。
