# 部品表 (HPX-W・HPX-TH・HPX-Core)

2026-10-30 作成。★は TARO さんのリストに無いが、回路に必要な部品です。配線は同じフォルダの `*_wiring.png` を見てください。

## HPX-W (重量センサ)

| 部品 | 数 | 使うところ |
|---|---|---|
| Seeed XIAO BLE nRF52840 | 1 | 本体 |
| ロードセル シングルポイント (ビーム型) SC601 120kg | 1 | 重さを測る |
| ★ HX711 モジュール | 1 | ロードセルの信号を数値にする (D0=DT, D1=SCK) |
| 積層セラミックコンデンサー 0.1µF 50V C0G 5mm | 1 | HX711 の VCC–GND (HX711 の近く) |
| 絶縁ラジアルリード型積層セラミックコンデンサー 100µF 6.3V 5mm | 1 | 電源の ＋–− (XIAO の近く、向きなし) |
| CR123A 用電池ケース | 1 | ＋→3V3、−→GND |
| CR123A 電池 | 1 | |

## HPX-TH (温度センサ)

| 部品 | 数 | 使うところ |
|---|---|---|
| Seeed XIAO BLE nRF52840 | 1 | 本体 |
| サーミスター 10kΩ (平行線タイプ) | 1 | 測る点 (A2) と GND の間 |
| ★ 抵抗 10kΩ 1% (金属皮膜) | 1 | D3 と測る点 (A2) の間 |
| 積層セラミックコンデンサー 0.1µF 50V C0G 5mm | 1 | 測る点 (A2) と GND の間 (ノイズよけ) |
| 絶縁ラジアルリード型積層セラミックコンデンサー 100µF 6.3V 5mm | 1 | 電源の ＋–− |
| CR123A 用電池ケース | 1 | ＋→3V3、−→GND |
| CR123A 電池 | 1 | |

ピンは試験スケッチ HPX_Thermistor_Test の割り当てです。HPX-TH 用の無線で送るファームはまだありません。

## HPX-Core (親機)

| 部品 | 数 | 使うところ |
|---|---|---|
| ESP32 開発ボード Freenove FNK0090B 4MB | 1 | 本体 |
| 積層セラミックコンデンサー 0.1µF 50V C0G 5mm | 1 | 電源の ＋–− (ボードの近く) |
| 絶縁ラジアルリード型積層セラミックコンデンサー 100µF 6.3V 5mm | 1 | 電源の ＋–− |
| CR123A 用電池ケース | 1 | ＋→ボードの 3V3 ピン (5V ピンではない)、−→GND |
| CR123A 電池 | 1 | |

CR123A は試験用の構成です。ESP32 の推奨電圧は 3.0〜3.6V で、CR123A (約3V) では Wi-Fi で送る瞬間に再起動することがあります。動くかは試さないとわかりません。電池をつないでいる間は USB を挿さないでください。

## 共通

- 配線用の線、ブレッドボードかユニバーサル基板、ピンヘッダー (手持ちに合わせて)
- USB で書き込むときは電池を外す
