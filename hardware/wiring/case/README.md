# ケースに合わせたタカチ基板の配線図

電池の種類ごとに、ケースに合わせたタカチのユニバーサル基板 (TNF シリーズ、2.54mm ピッチ) に部品を載せる図です。
穴の位置は「行の文字＋列の数字」(例: C14 は C 行の 14 列目) で書いてあります。

| 機器 | 電池 | 基板 | 図 |
|---|---|---|---|
| HPX-W | CR123A | TNF39-70 (70×39.5mm、穴 25×14) | [HPX-W_CR123A_TNF39-70.png](HPX-W_CR123A_TNF39-70.png) |
| HPX-W | 単3リチウム×2 | TNF34-124 (124×34mm、穴 47×12) | [HPX-W_AA_TNF34-124.png](HPX-W_AA_TNF34-124.png) |
| HPX-TH | CR123A | TNF39-59 (59×39mm、穴 21×14) | [HPX-TH_CR123A_TNF39-59.png](HPX-TH_CR123A_TNF39-59.png) |
| HPX-TH | 単3リチウム×2 | ケース LC115H-M2-D の推奨基板 | (寸法の確認待ち) |

- 回路とピンは小さい基板版 (`../HPX-W_pcb.png`・`../HPX-TH_pcb.png`) と同じです。基板が大きいので、HX711・SHT40 は立てずに、ピンヘッダの上に基板と平行に寝かせて付けます。
- 穴の数は販売店の掲載値 (TNF39-59: 14×21、TNF39-70: 14×25、TNF34-124: 12×47) です。四すみの取付穴の位置は目安なので、実物で確認してください。
- 作り直すときは `python3 gen_case_pcb.py <出力フォルダ>` で SVG を作ります。
