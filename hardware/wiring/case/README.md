# ケースに合わせたタカチ基板の配線図

電池の種類ごとに、ケースに合わせたタカチのユニバーサル基板 (TNF シリーズ、2.54mm ピッチ) に部品を載せる図です。
穴の位置は「行の文字＋列の数字」(例: C14 は C 行の 14 列目) で書いてあります。

| 機器 | 電池 | 基板 | 図 |
|---|---|---|---|
| HPX-W | CR123A | TNF39-70 (70×39.5mm、穴 25×14)。左下 44×22mm を切り取り、CR123A ケース (秋月 110192) を置く | [HPX-W_CR123A_TNF39-70.png](HPX-W_CR123A_TNF39-70.png) |
| HPX-W | 単3リチウム×2 | TNF34-124 (124×34mm、穴 47×12)。右側に電池ボックス (秋月 117271) を両面テープで貼る | [HPX-W_AA_TNF34-124.png](HPX-W_AA_TNF34-124.png) |
| HPX-TH | CR123A | TNF44-69 (69×44mm、穴 25×16、ケース SW-75B)。CR123A ケースの裏のピンを M6 (−)・M21 (＋) に差し、SHT40 は寝かせて付ける | [HPX-TH_CR123A_TNF44-69.png](HPX-TH_CR123A_TNF44-69.png) |
| HPX-TH | 単3リチウム×2 | ケース LC115H-M2-D の推奨基板の形 (本体 60×54.5mm ＋ 上の出っぱり 46×8.5mm、取付穴 φ2.5 ×4 を 53×40mm 間隔) にユニバーサル基板を切る | [HPX-TH_AA_LC115H.png](HPX-TH_AA_LC115H.png) |

- 部品は表から差し、線はすべて裏ですずめっき線でつなぎます。各図の下半分に「裏から見た図」(左右が逆) があります。
- 回路とピンは小さい基板版 (`../HPX-W_pcb.png`・`../HPX-TH_pcb.png`) と同じです。基板が大きいので、HX711・SHT40 は立てずに、ピンヘッダの上に基板と平行に寝かせて付けます。
- 穴の数は販売店の掲載値 (TNF44-69: 16×25、TNF39-70: 14×25、TNF34-124: 12×47) です。四すみの取付穴の位置は目安なので、実物で確認してください。
- 作り直すときは `python3 gen_case_pcb.py <出力フォルダ>` で SVG を作ります。
