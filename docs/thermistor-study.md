# サーミスター温度センサの検討 (秋月 107257)

2026-10-26

## 結論

**作れます。** 秋月 [107257]「サーミスター 10kΩ(平行線タイプ)」は SEMITEC 103AT-11 で、
25℃で10kΩ、B定数3435K (25/85℃)、抵抗値とB定数の許容差±1%、使用温度 -50〜105℃、
TPE被覆の平行線600mm付きです。1本200円。巣箱の温度計には十分な性能です。

XIAO nRF52840 なら、固定抵抗10kΩを1本足すだけで測れます。
おすすめは **重量センサ HPXW に組み込む** ことです (理由は最後の章)。

## 回路

```
XIAO D3 (測るときだけ HIGH) ──[ 10kΩ 1% 金属皮膜 ]──┬── XIAO A2 (D2)
                                                     │
                                          0.1µF ─────┤      ← A2のすぐ近くに
                                                     │
                                         サーミスター 103AT (平行線600mm、極性なし)
                                                     │
XIAO GND ────────────────────────────────────────────┘
```

- 上側の固定抵抗は 10kΩ・1%・金属皮膜 (温度係数の小さいもの)。0.1%品にすると誤差がさらに減る。
- 分圧の電源は 3V3 ピンではなく **GPIO (D3)** から取り、測るときだけ HIGH にする。
  つなぎっぱなしだと常に約150µA流れ、1年で約1.3Ah (単3リチウムの半分以上) を無駄にする。
- 0.1µF は600mmの線が拾うノイズ対策。GPIOをHIGHにしてから10ms待ってから読む (時定数は約0.5ms)。
- HPXW で使っているのは D0・D1 (HX711) なので、D2・D3 は空いている。

## 測り方 (電池電圧に左右されない方法)

ADC の基準を **VDD** にする (`analogReference(AR_VDD4)`)。分圧の電源も同じVDDなので、
ADC の読み値は「抵抗の比」だけで決まり、電池が3.2Vから2.7Vに下がっても値は変わりません (レシオメトリック測定)。

サーミスターが下側なので、12bit の読み値 `adc` (0〜4095) から

```
R_th = 10000 × adc / (4095 − adc)
```

分解能は 0〜35℃で 1℃あたり約35カウント (約0.03℃) で、十分です。

## 抵抗値から温度への換算

### B定数の式 (簡単だが低温でずれる)

```
1/T = 1/298.15 + ln(R_th / 10000) / 3435      (T はケルビン、℃ = T − 273.15)
```

B=3435 は 25℃と85℃の2点で決めた値なので、そこから離れるほどずれます。
SEMITEC ATサーミスターの標準抵抗値表 (0℃=27.28kΩ, 50℃=4.160kΩ など) と比べた計算では、
**0℃で約1.1℃、-10℃で約1.8℃、-20℃で約2.5℃ 高く出ます**。冬の外気温を測るなら問題になります。

### Steinhart-Hart の式 (おすすめ)

表の 0℃・25℃・50℃ の3点から係数を作りました。-20〜50℃で表とほぼ一致します (計算上の差0.05℃以内)。

```
L = ln(R_th)
1/T = A + B·L + C·L³
A = 8.880739e-4,  B = 2.514252e-4,  C = 1.922794e-7
```

> 表の値は SEMITEC の AT サーミスター標準表から取りました。念のため SEMITEC のデータシートと照らし合わせてください。

## 精度の見込み

| 要因 | 温度にすると |
|---|---|
| サーミスター本体の許容差 (R25 ±1%、B ±1%) | 0〜50℃で約±0.3〜0.5℃ |
| 固定抵抗 1% | 約±0.2℃ (0.1%品なら約±0.02℃) |
| ADC (8回平均) | 約±0.05℃ |
| 計 | 何もしなければ ±0.5℃前後 |

**1点校正** で ±0.2〜0.3℃まで詰められます。氷水 (よくかき混ぜた氷と水で0℃) に先端を入れるか、
手持ちの IBS-TH2 と一晩並べて差を取り、その差をオフセットとして引きます。

自己発熱: 流れる電流は約150µAで、10msだけなので無視できます (つなぎっぱなしでも0.1℃程度)。

## 低消費電力の工夫

- 分圧は GPIO から給電し、測る10〜20msだけ通電する (上記)。30分ごとなら平均電流は1nA以下。
- 測るのは HX711 と同じタイミング (30分ごと)。広告は今のまま1秒間隔でよく、追加の電力はほぼゼロ。
- `analogReadResolution(12)` と `analogOversampling(8)` で、ハードの平均にまかせる (CPUの起きている時間が短い)。
- 読み終わったら D3 を LOW に戻す (INPUT にしてもよい)。

## 屋外・巣箱内での注意

- **プロポリスで固められる**: ミツバチは巣内の異物をプロポリスで覆い、線をかじることもある。
  先端をステンレスや真鍮の細い管、または目の細かい金網で囲うと、取り出しや交換が楽になる。
- **置き場所で意味が変わる**:
  - 巣枠の上桟の間 (蜂児圏の真上) … 育児中は34〜35℃で安定する。下がれば育児停止・無王・群れの弱りのサイン。分蜂前の変化も見える。
  - 巣門近く・巣箱の外 … 外気温。直射日光が当たると10℃以上高く出るので、日よけ (百葉箱のような覆い) が要る。
  - ロードセルのそば … 重量の温度補正用。
- **配線**: 線は巣門や継ぎ目から通し、蓋で強く挟まない。延長はより線か、2芯のシールド線で。
  10kΩに比べて線の抵抗は小さいので、数m延ばしても誤差は出ません。延長部分のつなぎ目は熱収縮チューブとシリコンで防水する。
- **結露**: 巣内は湿度が高く、冬は結露する。XIAO 側の基板とコネクタは HPXW のケースの中に入れる。
- **湿度は測れない**: サーミスターは温度だけ。湿度が要る巣は IBS-TH2 を残す。

## HPXW に組み込むか、別ノードにするか

**HPXW に組み込むのがおすすめです。**

| | HPXW に組み込む | 別ノードを作る |
|---|---|---|
| 部品代 | サーミスター200円 + 抵抗・コンデンサ | XIAO・電池・ケースがもう1組 |
| 電池 | 共用 (増える消費はほぼゼロ) | もう1組の交換が増える |
| HPX-core の受信台数 (最大8台) | 増えない | 1台使う |
| HPX-core の変更 | **不要** (下記) | 新しい広告形式の受信を追加 |
| 向いている場面 | 重量を測る巣箱 | 重量計の無い巣箱、何本も測りたいとき |

### HPX-core を変えずに送る方法

今の HPXW の広告には [10..11] に「ノード内の温度 ×100」(nRF52840の内部温度) が入っています。
HPX-core v1.13 はこの欄を温度として受け取り、そのままサーバーへ送っています。
ここをサーミスターの温度に置き換えれば、**HPX-core もサーバーも変えずに** 巣の温度が記録されます。
(サーバー側ではまだこの温度で重量を補正していないので、置き換えても影響はありません。)

サーミスターが外れている・ショートしているとき (読み値が極端) は内部温度を入れ、シリアルに警告を出す形にします。

サーミスターを2本 (巣内と外気など) 使いたくなったら、広告データを18バイト以上に広げる新しい版が要り、
その時は HPX-core の `bleParseW` とサーバーの受信も合わせて変えます。
